Mannequins will now have a "voice"! That’s right—MoNTE has shown us that mannequins can "speak" using various settings: for instance, they can send messages one by one, trigger them when a player gets close, or repeat a message when clicked on.

As for the new chat system, it’s currently available to beta users on Android (I’m not sure if it’s available via TestFlight on iOS). It’s still in beta, but it is fully functional. When opened, it takes up the entire screen and includes a "/" button that displays recently used commands (typing "/" also brings these up). You can click on other players' usernames to "mention" them, which adds their name to the beginning of your message (e.g., [croissant] aurelmattnath: command_block: How’s it going?), and your own messages are highlighted.
