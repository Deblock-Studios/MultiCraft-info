Dua penambahan yang baru saja dilakukan:
- Kini Anda dapat memilih, di pengaturan, antara OpenGL dan Vulkan (di Android)/Metal (di Apple). Sebagai pengingat, ini adalah API grafis tingkat rendah, yang secara teori dapat memberikan peningkatan FPS. Adanya opsi untuk memilih adalah hal yang baik, terutama untuk perangkat yang tidak kompatibel dengan Vulkan/Metal.
- Tekstur armor telah dibuat ulang. Memulai ulang server akan memungkinkan Anda menikmatinya.
