Deux ajouts fraîchements réalisés :
- Il est désormais possible de choisir, dans les paramètres, entre OpenGL et Vulkan (sur Android)/Metal (sur Apple). Pour rappel, ce sont des API graphiques de bas niveau, permettant théoriquement un gain de FPS. L'option permettant le choix est une bonne chose, surtout pour les appareils incompatibles Vulkan/Metal. 
- Les textures des armures ont été refaites. Un redémarrage du serveur vous permettra d'en profiter.
