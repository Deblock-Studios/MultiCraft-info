You’ve been waiting for it—we all have—and block creation is now officially available! For a while now, we’ve been able to officially create our own blocks using a comprehensive system. You can paint each face of the block, choose its destruction speed and sound, and decide if it rotates, falls, acts as stairs, is bouncy, deals damage, or conducts Bluestone. You can also set its maximum stack size, smelting time, and light level! with "/ie block"
