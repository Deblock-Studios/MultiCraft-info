mod review!
(more mesecon!!)
1 adjustable blinky plant!
it will blink at whatever rhythm you want
(2 sec = on 2 sec then off 2 sec....)

2 conductor signal changer
(image 2)
if F is on the thing will light up, the current can pass! if o is activated the current no longer passes

3 double delayer
(image 3)
if you turn it on, 1 will light up then 2....

4 Entity detector!
set the detection radius then the mob name (it also works with the item name)

5 igniter
turns into fire for 1 sec if turned on

6 induction transmiter
transmits the current 1 block further...

7 injector controler
(image 7)
if one of the "in" parts receives current then "out" will blink...

8 confitureur mesecon :troll~1:
bluestone will stop working within a radius of 10 blocks...

9 the sayer (loudspeaker)
say the text you want to every player within a radius of 8 blocks

10 signal changer
(image 10)
if F is on, A is on and B is off
if 0 is on, B is on and A is off
when you place it, A and B are off

11 switch torch
I have no idea.
there's an "on" state but I don't know how to get to it....

12 the teleporter!
if a player is on it or within a radius of 2 blocks they'll be teleported to the nearest other teleporter (it must be aligned and less than 50 blocks away)
if none is found the player will be teleported on top of it....

13 wireless confitureur :troll~1:
all the wireless stuff within a small radius will stop working....

14 wireless stuff
choose a channel and all the other wireless things you've placed on the same channel will be connected
(if 1 is on, all the others will be on)
