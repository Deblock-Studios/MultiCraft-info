A new command has been introduced on Multicraft, allowing for the respawn point of EACH PLAYER to be set individually to a specific location—for example:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

The player "Macron" will now respawn at coordinates (0, 0, 0) every single time, even if they sleep in a bed.

This opens up a wide range of possibilities for server creators.

Additionally, another command—/wear—has been added to the test servers.

It allows for armor to be equipped onto players via the command itself.
