MultiCraft-এ একটি নতুন কমান্ডের আবির্ভাব ঘটেছে, এটি আমাদের প্রতিটি খেলোয়াড়ের respawn পয়েন্ট আলাদাভাবে একটি নির্দিষ্ট স্থানে নির্ধারণ করার সুবিধা দেয়, উদাহরণ:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

খেলোয়াড় Macron আবার 0 0 0-এ আবির্ভূত হবে, এবং সে বিছানায় ঘুমালেও প্রতিবারই তাই হবে

এটি সার্ভার নির্মাতাদের জন্য অনেক সম্ভাবনা উন্মোচন করবে

এবং টেস্ট সার্ভারে আরেকটি কমান্ডও যোগ করা হয়েছে — /wear

এটি কমান্ডের মাধ্যমে খেলোয়াড়দের আর্মার পরিধান করানোর সুবিধা দেবে
