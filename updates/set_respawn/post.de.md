Ein neuer Befehl ist auf multicraft erschienen. Er erlaubt es uns, den Respawn-Punkt von JEDEM SPIELER individuell auf einen bestimmten Punkt zu setzen, zum Beispiel:

/set_respawn Macron 0 0 0
Respawn-Punkt von „Macron" auf (0,0,0) gesetzt

Der Spieler Macron erscheint dann bei 0 0 0 wieder, und zwar jedes Mal, selbst wenn er in einem Bett schläft.

Das eröffnet Server-Erstellern jede Menge Möglichkeiten.

Und außerdem wurde auf den Testservern ein weiterer Befehl hinzugefügt: /wear

Er ermöglicht es, Spielern Rüstungen per Befehl auszurüsten.
