A new command has appeared on MultiCraft, it lets us set the respawn point of EACH PLAYER individually to a specific point, for example:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

The player Macron will respawn at 0 0 0, and that every time, even if he sleeps in a bed

this will open up plenty of possibilities for server creators 

and also another command was added on the test servers, /wear

it will allow equipping armor on players via the command
