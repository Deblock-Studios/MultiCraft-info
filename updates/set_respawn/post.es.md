Un nuevo comando ha visto la luz en multicraft, nos permite establecer el punto de respawn de CADA JUGADOR individualmente en un punto preciso, por ejemplo:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

El jugador Macron reaparecerá en el 0 0 0 y eso cada vez, incluso si duerme en una cama

esto permitirá abrir un montón de posibilidades al creador de servidores

y también se ha añadido otro comando en los servidores de prueba, el /wear

permitirá equipar las armaduras a los jugadores mediante el comando
