Une nouvelle commande a vue le jour sur multicraft, elle nous permet de mettre le point de respawn de CHAQUE JOUEURS individuellement a un point précis exemple:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

Le joueurs Macron réapparaitra au 0 0 0 et ça a chaque fois meme si il dort dans un lit

cela permettra d'ouvrir plein de possibilité au créateur de serveur 

et aussi une autre commande a été ajouté sur les serveur de test le /wear

elle permettra d'équipé les armures a des joueurs via la commande
