MultiCraft पर एक नया कमांड सामने आया है, जो हमें हर खिलाड़ी के respawn पॉइंट को अलग-अलग, किसी तय जगह पर सेट करने की सुविधा देता है, उदाहरण:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

खिलाड़ी Macron अब 0 0 0 पर दोबारा पैदा होगा, और हर बार ऐसा ही होगा, चाहे वह बिस्तर में सो भी जाए

इससे सर्वर बनाने वालों के लिए ढेरों संभावनाएँ खुल जाएँगी

और टेस्ट सर्वर पर एक और कमांड भी जोड़ा गया है — /wear

इसके ज़रिए कमांड से खिलाड़ियों को आर्मर पहनाया जा सकेगा
