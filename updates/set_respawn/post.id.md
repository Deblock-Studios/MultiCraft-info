Sebuah perintah baru telah hadir di MultiCraft, perintah ini memungkinkan kita untuk menetapkan titik respawn SETIAP PEMAIN secara individual ke titik tertentu, contohnya:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

Pemain Macron akan muncul kembali di 0 0 0 dan itu terjadi setiap kali meskipun ia tidur di tempat tidur

hal ini akan membuka banyak kemungkinan bagi pembuat server

dan juga ada perintah lain yang telah ditambahkan di server pengujian, yaitu /wear

perintah ini memungkinkan untuk melengkapi pemain dengan armor melalui perintah tersebut
