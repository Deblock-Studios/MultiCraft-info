images: [1.png, 2.jpg]

multicraft に新しいコマンドが登場しました。これを使うと、各プレイヤー個別のリスポーン地点を指定した座標に設定できます。例：

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

プレイヤー Macron は 0 0 0 でリスポーンするようになり、ベッドで寝た場合でも毎回そこに復帰します。

これにより、サーバー作成者の可能性が大きく広がります。

さらに、テストサーバーにはもう一つ /wear というコマンドも追加されました。

これはコマンドを使ってプレイヤーに防具を装備させることができるものです。
