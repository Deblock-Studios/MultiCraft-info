MultiCraft에 새로운 명령어가 등장했습니다. 이 명령어를 사용하면 각 플레이어의 리스폰 지점을 개별적으로 특정 지점에 설정할 수 있습니다. 예시:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

플레이어 Macron은 0 0 0에서 다시 나타나게 되며, 침대에서 자더라도 항상 그렇습니다.

이를 통해 서버 제작자에게 많은 가능성이 열릴 것입니다.

그리고 테스트 서버에는 또 다른 명령어인 /wear도 추가되었습니다.

이 명령어를 사용하면 명령어로 플레이어에게 방어구를 장착시킬 수 있습니다.
