Er is een nieuw commando verschenen op MultiCraft; het stelt ons in staat om het respawnpunt van ELKE SPELER afzonderlijk op een specifiek punt in te stellen, bijvoorbeeld:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

De speler Macron zal opnieuw verschijnen op 0 0 0, en dat elke keer, zelfs als hij in een bed slaapt.

Dit zal de maker van de server veel mogelijkheden bieden.

En ook is er een ander commando toegevoegd op de testservers: /wear.

Het maakt het mogelijk om spelers via het commando bepantsering te geven.
