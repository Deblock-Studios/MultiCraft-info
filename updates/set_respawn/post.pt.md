Um novo comando surgiu no multicraft, ele nos permite definir o ponto de respawn de CADA JOGADOR individualmente em um ponto preciso, exemplo:

/set_respawn Macron 0 0 0
Ponto de respawn de “Macron” definido para (0,0,0)

O jogador Macron reaparecerá em 0 0 0 e isso todas as vezes, mesmo se ele dormir em uma cama

isso permitirá abrir muitas possibilidades para o criador de servidor

e também outro comando foi adicionado nos servidores de teste, o /wear

ele permitirá equipar armaduras em jogadores através do comando
