На multicraft появилась новая команда — она позволяет задать точку возрождения КАЖДОГО ИГРОКА индивидуально в конкретной точке, например:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

Игрок Macron будет возрождаться на 0 0 0, и так каждый раз, даже если он спит в кровати

это откроет массу возможностей для создателя сервера

а также на тестовых серверах была добавлена ещё одна команда — /wear

она позволит надевать броню на игроков с помощью команды
