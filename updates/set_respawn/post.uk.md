У multicraft з'явилася нова команда — вона дозволяє встановлювати точку відродження для КОЖНОГО ГРАВЦЯ окремо в конкретному місці, наприклад:

/set_respawn Macron 0 0 0
Respawn point of “Macron” set to (0,0,0)

Гравець Macron відроджуватиметься на 0 0 0, і так щоразу, навіть якщо він спить у ліжку

це відкриє безліч можливостей для творця сервера

а також на тестових серверах було додано ще одну команду — /wear

вона дозволить вдягати броню на гравців за допомогою команди
