---
date: 2026-09-20
title: Game beralih ke Vulkan 1.3
---

Menurut Yota, sumber tepercaya dari MultiCraft, game ini telah mengganti mesin grafisnya ke Vulkan 1.3. Secara konkret, peralihan ini diklaim menawarkan hingga 2x lebih banyak FPS sekaligus membuat perangkat Anda lebih sedikit panas!
Kanal lain, Infos MultiCraft, tetap memberikan catatan dengan mengingatkan bahwa perubahan ini menimbulkan biaya pengembangan dan sebagian perangkat berisiko kini tidak lagi mampu menjalankan game tersebut. MoNTE48, pemilik game, juga memberikan catatan dengan mengumumkan bahwa peningkatan tersebut bergantung pada mode permainan. Dalam mode multipemain, penurunan FPS akan jauh lebih sering terjadi.
