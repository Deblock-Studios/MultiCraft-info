Les véhicules sont désormais craftables !
La recette (principalement de l’hélicoptère) est très complexe. Les véhicules restent disponibles dans le shop.

Pour les faire fonctionner, il faut se baisser + clic pour y mettre du carburant (=charbon). Ensuite le véhicule pourra démarrer !

Comme vous pouvez le voir sur les images et vidéos, nous avons surtout testé l’hélicoptère.
Il peut voler sans limite de taille, nous permet de nous déplacer dans tous les sens et permet aussi de rester stagne dans les airs.
Il ne possède pas de siège passager, mais on peut transporter un passager dessus. Il suffit que la personne soit sur l’hélicoptère et saute en boucle.

Nous vous tiendrons informés de leur arrivée sur les serveurs normaux !
